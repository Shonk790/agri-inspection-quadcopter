# Checklists

## Before leaving
- [ ] Batteries charged (balance-charged), count packs
- [ ] Props undamaged, tight, correct CW/CCW
- [ ] Mission file loaded on the ground station; SD card / camera storage free
- [ ] Weather check: wind within limits, no rain, good visibility

## At the field
- [ ] Choose a clear take-off area, bystanders kept away
- [ ] Power up transmitter first, then aircraft
- [ ] GPS lock (>= 8 satellites, low HDOP), compass OK, home position set
- [ ] Battery voltage and failsafes verified
- [ ] Radio range / telemetry link check
- [ ] Controls respond correctly (props off, then on)
- [ ] Short hover test (~2 m), listen for vibration, check stability
- [ ] Switch to Auto and start the mission; keep line of sight

## After flight
- [ ] Disarm, disconnect battery, cool down before charging
- [ ] Check motors/ESC temperature, props, frame
- [ ] Download logs and images; review vibration and battery data
- [ ] Note issues for the maintenance log
